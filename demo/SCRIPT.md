# Spike Bench demo video

Narrated 1080p walkthrough of the neurophysiology workbench: the
Hodgkin-Huxley clamp tab with presets and live stats, the TTX channel
block, the STDP microcircuit with weight trajectories, correlation and
raster, the f-I sweep and phase portrait, the verified export lab and
self-test battery, and the live verification card. Everything below is
produced locally and repeatably; no API keys, no network calls, no
signed-in browser.

## Files

| File | Role |
| --- | --- |
| `demo/narration.txt` | Voiceover source. One sentence per line, blank line between paragraphs. |
| `demo/steps.json` | The drive plan. `at` steps pin actions to narration marks (`"mark": "2.1"` = paragraph 2 sentence 1). |
| `demo/timing.json` | Measured per-sentence start/duration from the synthesized audio. Regenerated by `synth`. |
| `demo/narration.wav` | Assembled voiceover (Aariv OmniVoice clone, `mlx-community/OmniVoice-bf16`, `voice-ref.wav`, seed 1, 24 kHz mono). |
| `demo/captions.ass` | Lower-third captions burned into the video. |
| `demo/spike-bench-demo.srt` | Companion captions file for upload. |
| `demo/test-proof.txt` | Real outputs of the Node suite and the honesty harness, captured during `capture` and shown on screen near the end. |
| `demo/proof.html` | The on-screen verification card rendered from `test-proof.txt`. |
| `demo/spike-bench-demo.mp4` | The finished video. |
| `scripts/record-demo.mjs` | The whole pipeline: `synth`, `capture`, `check`, `all`. |
| `scripts/omnivoice_say.py` | Batch OmniVoice helper (loads the model once per job; per-unit seed override for retakes). |
| `scripts/serve.mjs` | Zero-dependency static server used by `capture`. |

## Reproduce

```bash
npm run demo:synth     # narration.txt -> narration.wav + timing.json + captions
npm run demo:capture   # proof + serve + headless Chrome drive -> demo/spike-bench-demo.mp4
npm run demo:check     # ffprobe report
```

`synth` writes one OmniVoice batch job for the missing sentences and runs
it once under `nice -n 19`, so a re-run only synthesizes what changed.
`capture` first writes `demo/test-proof.txt` from live command output
(the Node suite plus the station honesty harness) and refuses to record
unless every check is green, then serves the repo on an ephemeral port
and drives the app in a throwaway headless Chrome (empty profile,
ephemeral CDP port, real mouse and key events, a visible drawn cursor).
The screencast resamples to a constant 30 fps and muxes the narration
plus burned captions in one ffmpeg pass (`yuv420p`, `color_range=tv`,
`+faststart`, `aac` 24 kHz). All temp files live in `SPIKE_DEMO_TMP`
(or a fresh `/tmp/omnivoice-l159-*` dir) and are deleted on exit.
Downloads are denied at the browser level and the drive aborts if the
page ever leaves the demo origin.
